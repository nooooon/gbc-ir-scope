### NEC 形式の規格値との比較

| 項目 | 実測 | 規格値 | 差 |
|------|-----:|-------:|---:|
| リーダー ON | 9042 | 9000 | +0.5% |
| リーダー OFF | 4516 | 4500 | +0.4% |
| ビット ON | 561 | 560 | +0.2% |
| ビット OFF（0） | 550〜555 | 560 | −1〜2% |

- カウント換算（5.245µs）は規格値と 0.5% 程度で一致する。リモコン側の発振子の誤差（±0.5% 程度）と同じくらいなので、換算は正しいとみてよい
- N が 1 回分（ON 34 / OFF 33）より 2 つずつ多いのはリピート信号（約 40ms のすき間 → 9ms ON → 2.25ms OFF → 560µs ON）。OFF の MAX 41399µs がそのすき間
- ビットの OFF が規格値より少し短く、ON が少し長いのは、受光部の立ち上がり・立ち下がりの遅れによる可能性がある（純正 GBC と比べたい点）

### 搬送波

- RAW の CARRIER は 1.7kHz と表示された。これは集計のバグで、塊の途中の一瞬の途切れ（短い OFF）を搬送波の 1 周期として数え、ON 560µs ぶんまで周期に含めていた（1 / 588µs ≒ 1.7kHz）
- 修正後は ON も OFF も 100µs 未満の組だけを搬送波として数える
- Chromatic の受光部からは 38kHz の搬送波は見えず、塊として出てくるとみられる。RAW の N が BURST の N とほぼ同じなら確定（未確認）
